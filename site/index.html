Praetorium

An intelligent shipboard command platform for Elite Dangerous

All systems. One command.

Omnia sub uno imperio.

In development

Praetorium aims to bring compatible community tools, local game data and intelligent assistance into one command platform. Its current desktop foundation includes journal monitoring and views for navigation, markets, fleet, exploration and engineering.

Context-aware conversations, interconnected planning workflows and additional command interfaces are planned. Production uploads, automatic updates and hosted AI remain disabled.
