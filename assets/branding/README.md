# Praetorium brand concept

The emblem uses a Roman pediment and three columns on a clipped command-console tile, with an ivory navigation star above it. A flat silhouette gives the mark a legible small-size variant. It was created as new geometric artwork for this assignment, using no reference logo, template, typeface or stock artwork. The proposed repository license for these sources is GPL-3.0-or-later, subject to owner review. The color design uses imperial gold, midnight black, gunmetal and ivory.
