# Website preview

Run `python tools/site/build.py --output target/site-preview` and `python tools/site/check.py --root target/site-preview`. Open the generated `index.html` to review it locally.

The Website preview workflow validates the local Praetorium page. The previous versions of the Elite Nexus site and its generation tools remain available in Git history. The preview contains the original Praetorium emblem and attributes its application foundation to Elite Nexus.
